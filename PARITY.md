class reference). Every entry below is something Roblox has that a script here cannot reach -- which
makes it a job, not a note. A class is present when the runtime declares it. A member is present when a
Luau script reads it: the generator makes one instance of each class (`game:GetService`, `Instance.new`, or a

the error says it is not a valid member, so a read that fails for a missing capability still counts.
